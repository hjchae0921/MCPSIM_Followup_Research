Procedure:
Do the following, in order.
1. Read the existing mesh tags and find the entity indices carrying each prescribed boundary marker value.
2. Retrieve the i-th subspace of the parent function space for each constrained field component; use the parent space itself for whole-field constraints.

5. Create the Dirichlet boundary conditions using the prescribed values and the target degrees of freedom of the original problem.
